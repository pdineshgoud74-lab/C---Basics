# C Language Programs 💻

This repository contains my C programming practice files and mini projects.  
I created this while learning the basics of programming, logic building, and problem solving.

---

## 📘 Topics Covered
- Variables and Data Types  
- Operators and Expressions  
- Conditional Statements (`if`, `else`, `switch`)  
- Loops (`for`, `while`, `do-while`)  
- Arrays and Strings  
- Functions  
- Pointers and Structures  
- File Handling (basic programs)

---

## 🧩 Example Programs
- `sum_of_two_numbers.c` — Adds two numbers  
- `largest_number.c` — Finds the largest of three numbers  
- `factorial.c` — Calculates factorial using loops  
- `pointers_basics.c` — Demonstrates pointer usage  
- `file_read_write.c` — Simple file I/O example
